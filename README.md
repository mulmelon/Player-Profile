# [Player-Profile](https://modrinth.com/mod/player-profile)

**A simple, interactive player profile viewer for Minecraft.**

Player Profile GUI (PPGUI) is a client-side Minecraft Fabric mod that lets you look up Minecraft players and explore their profiles through an interactive interface.

View player skins in 3D, inspect capes, check UUIDs, discover locator bar colors, and more — all without leaving Minecraft!

Developed by **MulMelon**.

## Features

- **Player Lookup** — Search for Minecraft players by username.
- **Interactive 3D Skin Viewer** — Rotate player models to view skins from different angles.
- **Cape Viewer** — View a player's equipped Minecraft cape.
- **Elytra Preview** — Preview Elytra using vanilla Minecraft animations, including a flying pose.
- **Customization Controls** — Toggle capes, Elytra, and the flying pose.
- **Locator Bar Colors** — View a player's locator bar color with HEX and RGB values.
- **UUID Information** — View player UUIDs.
- **Player Heads** — Get a command for obtaining a player's head.
- **Skin Downloading** — Save player skins using a native file dialog.
- **Localization** — Available in English and Korean.
- **And MUCH MORE!**

## How to Use

1. Install PPGUI and its required dependencies for a supported Minecraft Fabric version.
2. Launch Minecraft.
3. Press **J** (configurable in Minecraft's keybind settings) to open the PPGUI home screen.
4. Enter a Minecraft username to look up a player.
5. Explore their profile using the interactive 3D viewer and available controls.

Some profile information requires an internet connection to retrieve.
